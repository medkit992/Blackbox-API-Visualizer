Privacy & data access
Allow Blackbox to read network traffic?

        
Blackbox reads network data from the page currently inspected in DevTools so it can build the request table, diagnostics, session insights, and Request Stories.

        
This data may include URLs, headers, cookies or authentication values, query parameters, request bodies, response data, source resources, and timing metadata. Blackbox processes this information locally in the DevTools extension and does not send captured traffic to Blackbox servers.

        
Response bodies are retrieved automatically when you select a captured request. When tracing where a resource came from, Blackbox may also inspect a bounded set of recent successful Fetch/XHR responses and source resources exposed by DevTools to find exact URL relationships and authored source locations. If a generated same-origin script has a conventional sibling source-map file, Blackbox may request that map locally from the inspected site to resolve the original source file. This context stays local. You can pause capture, clear the current session, or revoke access from Privacy at any time.

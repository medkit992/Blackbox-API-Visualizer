Privacy & data access

        
Allow Blackbox to read network traffic?

        

          Blackbox reads network data from the page currently inspected in DevTools so it can
          build the request table, diagnostics, session insights, and network graph.
        

        

          This data may include URLs, headers, cookies or authentication values,
          query parameters, request bodies, response data, and timing metadata.
          Blackbox processes this information locally in the DevTools extension and does not
          send captured traffic to Blackbox servers.
        

        

          Response bodies are retrieved only when you explicitly choose Load Response.
          You can pause capture, clear the current session, or revoke access from Privacy at any time.
